## 📌 About The Project

**Seaon.app** is a Python-based web application that serves as **Version 1 of Seaon Tapes**. It features a light backend architecture powered by SQLite for databasing and Flask/Python for routing.

## 🛠️ Tech Stack

* **Backend:** Python (`app.py`), Flask
* **Database:** SQLite (`database.db`, `database.py`, `database.sql`)
* **Frontend:** HTML/CSS Templates (`templates/`, `static/`)
* **Execution Script:** Batch Script (`start.bat`)
